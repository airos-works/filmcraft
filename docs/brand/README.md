# ArtCraft brand marks: removed from this fork

Upstream FilmCraft keeps the ArtCraft name, wordmark and mark (the "ArtCraft Marks") here. They are
trademarks of the ArtCraft Team, not open source, and [`LICENSE-brand.txt`](LICENSE-brand.txt) asks
distributed forks and modified versions to remove them and not to present themselves as ArtCraft
products. This fork (airos-works/filmcraft, distributed as air/OS packages and in air/OS images) is
one, so the image files were removed: the app draws nothing where upstream draws the wordmark
(`crates/ui-egui/src/brand.rs`), and the README credits upstream in plain text. FilmCraft for air/OS
is based on FilmCraft by the ArtCraft team.
